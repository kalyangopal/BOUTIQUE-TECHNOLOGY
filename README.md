# AURA Boutique Virtual Try-On — Premium React Demo

Client-first interactive boutique kiosk/admin demo.

## Current scope
- React + Vite frontend
- Premium responsive UI/UX for desktop, tablet and mobile
- Dashboard with stock/product count, online try-ons, styling sessions and low-stock indicators
- Four garment categories: Saree + Blouse, Salwar Kameez, Lehenga, Anarkali Suit
- Product catalog and demo Add Product flow
- Inventory screen
- 2D virtual styling workflow
- Animated interactions and responsive transitions using Framer Motion
- Ultra-HD remote fashion imagery
- Explicit 3D Visualization “Coming Next” presentation
- No camera permission requested
- No MongoDB connection and no real database writes

## Run
```bash
npm install
npm run dev
```
Then open the local Vite URL.

## Production build
```bash
npm run build
npm run preview
```
